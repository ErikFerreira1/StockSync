# StockSync Frontend

Aplicação React + TypeScript separada do backend, consumindo a API Spring Boot.

## Desenvolvimento

1. Inicie a API na raiz do repositório com `docker compose up --build`.
2. Entre nesta pasta, instale as dependências com `npm install`.
3. Copie `.env.example` para `.env.local` se quiser apontar para outra API.
4. Rode `npm run dev` e abra `http://localhost:5173`.

As credenciais padrão do perfil demo estão documentadas no README da raiz.
